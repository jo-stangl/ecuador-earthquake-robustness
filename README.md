# Robustness checks explorer

Interactive companion to the Supplementary Information of *Resilience to natural disasters and
shock propagation in firm-level production networks* (Stangl, Robalino, Astudillo-Estevez,
Thurner). For each main-text exhibit it shows the robustness checks reported in the SI.

Every number on the page is an aggregate regression result (coefficients and standard errors)
or, for the disruption score, a share of firms, as reported in the SI. The page contains no
firm-level data.

Open the page: https://jo-stangl.github.io/ecuador-earthquake-robustness/

This is a temporary location; the page will move to the paper's code repository on publication.
